Not what is on the disk. What grew.

Disk space rarely disappears all at once. Windows updates, browser and messenger caches, shader caches and developer tools grow a little every day, until one morning the drive is full and nothing looks guilty.

Tools like WizTree or WinDirStat show what is on the disk right now. Enigma Disk takes snapshots and compares them, so it answers a different question: which folders grew this week?

Everything stays on your computer. Scanning only reads file sizes and never changes the disk.

  • Snapshots

    A fast multi-threaded scan records every folder over 1 MB and the 300 largest files. About 20 seconds on repeat runs.

  • What grew

    Compare with yesterday, a week, a month ago or the first snapshot, with a plain-language hint for well-known folders.

  • Folders and files

    Browse any snapshot with sizes, share of the parent folder and change over the week, plus the largest files.

  • Safe clean-up

    Only well-known caches and temporary files. Files in use are skipped, nothing is deleted without confirmation.

  • Daily snapshots

    Through Windows Task Scheduler: no background service, low priority, catches up after the PC was off.

  • Private

    Everything stays in your local app folder. Nothing is sent anywhere. English and Russian interface.

How it works

Three steps, no guessing

  1. 01

    Take a snapshot

    The first scan of a 240 GB system drive with about a million files takes around a minute and a half. After that, Windows takes one for you every day.

  2. 02

    See what grew

    Enigma Disk shows the folders that actually grew, not the whole chain of parents. You see …\NVIDIA\DXCache +3 GB instead of C:\Users +3 GB.

  3. 03

    Clean up safely

    Temp files, browser and messenger caches, GPU shader caches, crash dumps, old Windows updates, developer caches and the Recycle Bin. Links are never followed.

The installer

  • Installs for the current user, no administrator rights needed.
  • Adds Start menu and, if you like, desktop shortcuts.
  • Shows up in Settings → Apps, where it can be uninstalled.
  • A newer installer updates the app and keeps your snapshot history.
  • A portable version that needs no installation is also available.

Installing

Enigma Disk is not code-signed yet, so Windows SmartScreen may show a blue “Windows protected your PC” window the first time. This is normal for small independent apps.

  1. Run EnigmaDiskSetup.exe.
  2. If the blue window appears, click More info.
  3. Click Run anyway and follow the installer.
